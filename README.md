# Myntra-Clone-project

A responsive **Myntra-inspired e-commerce website UI clone** built using HTML and CSS. This project recreates the visual structure of the Myntra homepage, including the navigation bar, search section, product categories, promotional banners, footer, and a fixed offer tab.

## 🚀 Features

* Myntra-inspired navigation header
* Myntra logo and category navigation
* Search bar with Google Material Symbols icons
* Profile, Wishlist, and Bag action icons
* Promotional banner section
* "Medal Worthy Brands to Bag" section
* "Shop by Category" section
* Responsive flexbox-based product layouts
* Myntra-style footer with multiple information columns
* Google Play and Apple App Store download buttons
* Customer policy and useful links sections
* Original product and return-policy information section
* Fixed **"UPTO ₹300 OFF"** offer tab on the right side
* Hover effect on navigation links

## 🛠️ Technologies Used

* **HTML5** – Used to structure the webpage and its different sections.
* **CSS3** – Used for styling, layouts, spacing, typography, colors, and positioning.
* **Google Material Symbols** – Used for search, profile, wishlist, and shopping bag icons.
* **Flexbox** – Used to create the navigation, product category, and footer layouts.

## ▶️ How to Run

1. Download or clone the project.
2. Open the project folder in VS Code.
3. Install the **Live Server** extension if required.
4. Open `index.html`.
5. Right-click the file and select **Open with Live Server**.

The project will then open in your browser.
